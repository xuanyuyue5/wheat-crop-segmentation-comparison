# Data Directory

Image datasets are intentionally not included in this repository. Place local copies here when running the experiments.

Expected deep learning split:

```text
data/train/
data/validation/
data/test/
```

Optional notebook datasets:

```text
data/EWS-Dataset/
data/DataforYuetal/
```

Generated results, trained weights, and prediction visualizations should stay local and are ignored by Git.
